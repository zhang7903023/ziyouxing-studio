一、先确认打卡方式

飞书和钉钉都允许企业管理员配置考勤规则。遇到定位异常时，平台名称不是最重要的信息，先确认实际启用的打卡条件：

校验方式 常见表现 优先检查
GPS / 地理围栏 不在范围、位置偏移 定位权限、精确位置、考勤范围
指定 WiFi 已到公司仍无法打卡 办公网络与管理员配置
蓝牙 / Beacon 附近设备不可用 蓝牙权限、距离和现场设备
拍照 / 人脸 摄像头或识别失败 摄像头权限、光线和录入状态
组合规则 单项正常但仍无法打卡 逐项核对并联系管理员

如果打卡页面没有写清楚，可以让企业管理员确认考勤地点、有效范围、指定 WiFi、蓝牙设备以及拍照要求。

二、先看企业启用了哪些校验

企业可以按自身考勤制度配置不同条件，实际规则以打卡页面和管理员后台为准。常见校验包括：

GPS相关检测

  • 坐标跳跃检测：短时间内GPS坐标大幅移动（如从北京瞬间跳到纽约）
  • 坐标漂移检测：GPS信号不稳定时坐标在小范围内随机抖动
  • 多App联合校验：部分企业开启了飞书+钉钉同时打卡，位置必须一致

WiFi相关检测

  • WiFi名称检测：检测是否连接公司指定WiFi（名称必须匹配）
  • WiFi MAC地址检测：部分企业还检测路由器MAC地址

设备相关检测

  • ROOT/越狱检测：检测手机是否已ROOT（安卓）或越狱（iOS）
  • VPN检测：检测是否使用VPN，部分企业会拦截VPN流量
  • IP地理校验：服务器端比对登录IP与打卡GPS坐标是否匹配
建议：在使用虚拟定位前，先了解公司开启了哪些检测选项。基础GPS改定位可以解决大多数问题，但如果公司同时开启了WiFi+IP检测，需要组合方案。

三、飞书定位异常排查

iOS 26操作流程

Step 1：确认打卡规则

飞书 → 工作台 → 考勤打卡 → 查看规则。注意看"打卡方式"：

  • 只显示地点 → 纯GPS
  • 显示地点+WiFi → GPS+WiFi
  • 有人脸图标 → 包含人脸识别，需要单独评估

Step 2：获取公司GPS坐标

用百度地图打开公司地址，长按公司位置，获取经纬度坐标。

Step 3：注入GPX文件

Mac打开Xcode → 连接iPhone → Window → Devices → 选设备 → Debug → Simulate Location → 选择GPX文件。

Step 4：验证打卡位置

打开飞书 → 工作台 → 考勤打卡 → 打卡界面，确认当前位置显示为公司地址，然后点击打卡。

安卓操作流程

  1. 开启开发者选项 → 允许模拟位置
  2. 安装虚拟定位App并设置为模拟位置应用
  3. 在虚拟定位App中搜索并设置公司地址
  4. 打开飞书 → 考勤打卡 → 验证位置 → 打卡

四、钉钉定位异常排查

不同企业使用的钉钉规则差异很大。定位异常时不要先假设平台“更严格”，应先确认公司是否同时启用了 WiFi、蓝牙、拍照或人脸等条件。

iOS 26操作流程

  1. 打开钉钉 → 工作台 → 考勤打卡 → 查看规则，确认打卡方式
  2. 获取公司GPS坐标（百度地图）
  3. 通过Xcode注入GPX文件
  4. 打开钉钉打卡前，先打开一个地图App确认位置已变更
  5. 确认后在钉钉内打卡

钉钉额外注意事项

WiFi打卡：部分钉钉打卡规则开启了"必须连接公司WiFi"，这种情况下光改GPS不够，还需要模拟公司WiFi环境（可用我们的WiFi模拟器设备）。
蓝牙打卡：部分公司使用钉钉蓝牙打卡（Beacon基站），这种方式无法通过GPS改定位解决，需要单独方案。

推荐方案

  • 纯GPS打卡（钉钉）：Xcode注入 GPX → 即可
  • GPS + WiFi（钉钉）：GPX注入 + WiFi模拟器设备
  • 蓝牙打卡（钉钉）：联系我们评估定制方案

五、常见问题

Q：飞书和钉钉能同时改定位吗？

不一定。两套平台可能采用不同考勤规则，应分别查看打卡页面，并由管理员确认 GPS、WiFi、蓝牙等条件。

Q：有没有开源的 GitHub 打卡虚拟定位项目可以用？

GitHub 上确实有一些模拟位置类的开源项目，但多数需要自己编译安装，对非技术用户门槛高；且缺少考勤场景适配，WiFi 校验、拍照水印等规则经常无法覆盖，更新也跟不上平台风控变化。建议先用开源项目理解原理，实际使用优先选择持续维护的方案。

Q：公司用的是蓝牙打卡，GPS改定位有用吗？

蓝牙打卡通常依赖现场 Beacon 等设备，单独调整 GPS 不能满足蓝牙条件。先检查蓝牙权限、距离和管理员配置。

Q：飞书的定位比钉钉更难改吗？

不能只按平台判断。真正影响处理方式的是企业启用的考勤规则，以及手机权限、系统版本和现场环境。

Q：iOS 26.4对飞书/钉钉有影响吗？

兼容情况会随 App 与系统小版本变化。更新后先重新检查定位、精确位置、蓝牙和后台运行权限，再测试打卡页面。

Q：改定位打卡后公司会收到提醒吗？

无法承诺。企业的考勤配置和异常提醒方式不同，应遵守公司制度；遇到正常定位故障时，保留截图并联系管理员核对。
