海外手机卡与网络配置

人在国内或长期在海外，怎么保住一个美国号码、怎么收验证码、怎么打电话——这件事的答案完全取决于你用的是 Tello、Ultra Mobile 还是境外 eSIM。本文把三条路径讲清楚。

先说结论

海外号码在国内能用，走的是三条完全不同的路：

① Wi-Fi Calling（VoWiFi）——通过 WiFi 拨打接听美国号码，费率等同美国本地，不产生漫游费。Tello 只能走这条。
② 中国境内漫游——手机直接接入中国移动或联通的网络，没有 WiFi 也能收短信。Ultra Mobile PayGo 支持。
③ 境外数据 eSIM——只解决上网，通常不给号码，但数据经境外网关出口。

最容易踩的坑：很多人看到信号栏显示「无服务」就以为卡废了，其实只要 Wi-Fi 通话能打通，卡就是活的。

一、为什么会有「海外卡在国内用」这个需求

把号码当成一项资产来维护，而不是当成流量。真正需要长期保留一个美国号码的人，通常是为了这四件事：

1. 账号绑定与验证码

邮箱、支付、社交、云服务的两步验证都绑在这个号码上。号码没了，账号找回链就断了。

2. 接收美国来电

银行客服、机构回访、快递联系，都需要有人能接到这个号码的来电。

3. 保留号码归属

换号意味着所有绑定关系都要重建，成本远高于每月几美元的月租。

4. 数据出口环境

部分场景需要非内地的网络出口，境外 eSIM 的数据漫游天然满足这一点。

理解这一点，就能理解为什么「保号」比「上网」更重要——大多数人的痛点不是没流量，而是号码失效后收不到验证码。

三、Tello 与 Ultra Mobile PayGo 怎么选

两者都跑在 T-Mobile 网络上，都是预付费、无合约。差别集中在「没 WiFi 时能不能用」这一件事上：

对比项 Tello Ultra Mobile PayGo
网络 T-Mobile T-Mobile

eSIM 支持 支持，可即时开通 视购买渠道与套餐而定
中国境内漫游 不支持，回国后必须靠 WiFi 通话 支持，无 WiFi 时也能通过漫游收短信
适合谁 长期有稳定 WiFi、需要通话分钟较多 以收短信为主、担心没 WiFi 时失联

选型建议：如果你的核心诉求是「收验证码不能断」，优先考虑支持境内漫游的那一类；如果你主要在固定场所（家里、办公室都有 WiFi）并且需要打电话，Tello 这类走 WiFi 通话更划算。价格与套餐内容以运营商官网当期为准，本文不给具体报价。

四、Tello 在国内的使用流程

Tello 的机制是「无漫游 + 纯 WiFi 通话」，所以操作顺序很关键：

  1. 注册并确认机型兼容。在官网用邮箱注册，然后用官方的机型检测入口输入手机 IMEI，确认设备已解锁且兼容 T-Mobile 网络。
  2. 选套餐与 SIM 形态。按需组合分钟、短信与流量。仅保号用途可以把流量选到最低档。优先选 eSIM，可以即时开通，实体卡需要国际邮寄。
  3. 填写紧急服务地址。账户里需要填写用于紧急呼叫的地址信息，这一项不填会影响功能启用。
  4. 在美区网络环境下完成激活。激活页面要求美国网络出口，在境内激活需要自行解决网络环境问题。这一步是很多人失败的原因。
  5. 开启 Wi-Fi 通话。iPhone：设置 → 电话 → Wi-Fi 通话；安卓：设置 → 网络和互联网 → SIM 卡 → 选择 Tello → 打开 Wi-Fi 通话。
  6. 验证是否真的激活成功。不要看信号格。正确做法是打开 Wi-Fi 通话后，试着拨一个国内号码，能接通说明卡已经活了。

最容易被误判的一点：Tello 没有国际漫游，回到国内后信号栏显示「无服务／无运营商」是正常现象，不代表卡没激活。判断标准只有一个——Wi-Fi 通话能不能拨通。已经设置了但显示无服务就急着退款或换卡，是最常见的浪费。

五、Ultra Mobile 在国内的使用流程

流程与 Tello 类似，但多了一条兜底路径：

  1. 购买 SIM 卡（官网或授权渠道），确认购买的是支持境内漫游的套餐版本。
  2. 在美国网络出口环境下完成激活。
  3. 开启 Wi-Fi 通话：iPhone 设置 → 电话 → Wi-Fi 通话；安卓在 SIM 卡设置里打开。
  4. 没有 WiFi 时，手机会自动接入中国移动或联通的网络，可以通过漫游接收短信。
  5. 开启自动续费，避免因余额不足被停机。

漫游资费与可用性由运营商与当地网络共同决定，且可能随时间调整。如果你打算长期依赖漫游收码，建议每隔一段时间验证一次接收是否正常，不要等到紧急用时才发现断了。

六、Wi-Fi Calling 在国内打不开的 6 个原因

这是咨询量最高的一个问题。按出现频率从高到低排查：

# 原因 怎么确认
1 运营商账户未开通该功能 登录账户后台确认 Wi-Fi Calling 状态为已启用
2 紧急服务地址等账户信息未填 账户资料页补齐，Tello 用户特别容易漏
3 网络出口到不了通话服务器 更换网络环境（换一个 WiFi 或改用热点）测试开关状态
4 部分运营商要求连接原生网络才能首次启用 若曾在美区启用过，回国后一般可保持；从未启用过的账户会非常困难
5 手机端开关未打开或需重新识别 SIM 重新插拔 SIM／重启后再次打开开关
6 基站或通话服务器侧临时不可用 过一段时间或换个时段重试，社区曾出现集中恢复的情况

社区用户反馈中提到，T-Mobile 系运营商（含 Tello、Ultra Mobile 等）的 Wi-Fi 通话服务器使用的地址段在境内曾出现不可达，需要把该地址段通过路由器层级转发才能恢复。这类信息变动频繁，我们不做统一结论，遇到时按上表顺序排查即可。

七、eSIM 能不能在中国用

这里要区分两件完全不同的事，混淆会导致买错：

类型 发行方 在中国能否使用 办理要求
境外发行的数据 eSIM 境外运营商或旅行 eSIM 服务商 可以，漫游接入内地网络 需在入境前完成安装，境外平台的下载服务器在境内不一定可达
中国内地运营商的手机 eSIM 中国移动 / 联通 / 电信 仅限少数机型，且需到店或营业厅办理 需中国身份证实名核验

关于国行 iPhone：中国内地销售的绝大多数 iPhone 机型采用双实体 nano-SIM 设计，没有 eSIM 硬件。中国自 2025 年 10 月起开放了运营商手机 eSIM 业务，但支持机型范围很有限。如果你买的是国行 iPhone，想用 eSIM 之前一定要先确认具体型号，不要只看「支持 eSIM」这句话。

为什么境外 eSIM 在境内的网络体验更接近境外？因为漫游流量的架构就是把数据从内地网络带出去、经境外网关出口，这是漫游本身的工作方式，不是某个产品的特殊功能。它只对移动数据生效，一旦连上咖啡馆或酒店的 WiFi，就回到本地网络的规则。

八、海外号码长期保号

号码被回收通常不是意外，而是三个动作没做：

  1. 开启自动续费。绝大多数预付费号在余额不足且长时间未续费后会被回收，社区反馈中常见的门槛是余额不足且超过 60 天未续费。以运营商条款为准。
  2. 保持账户活跃。定期产生一次通话或短信记录，避免被判定为长期不用。
  3. 不要把开机当唯一检测手段。没有 WiFi 时信号栏无服务是正常的，定期用 Wi-Fi 通话拨一次号才是有效的存活检测。

九、收验证码的正确预期

验证码能不能收到，取决于两层：

  • 运营商层：号码是否在网、是否能接短信（Wi-Fi 通话下能否收短信取决于运营商支持；漫游状态下通常可以）。
  • 发送方层：部分机构对 VoIP 号码、漫游号码或预付费号码有限制。这是对方的风控策略，运营商层面无法解决。

所以「所有验证码都能收到」这个预期本身是不成立的。如果你要绑定的机构非常关键，先做一次小额验证测试，确认能收到再继续。

常见问题

Tello 在中国能用吗？

能用，但只能靠 Wi-Fi Calling。Tello 不提供国际漫游，回到中国后信号栏显示无服务是正常现象，电话和短信都走 Wi-Fi 通话。前提是账户已启用 Wi-Fi 通话，且网络出口能连到运营商的通话服务器。

Tello 和 Ultra Mobile PayGo 有什么区别？

两者都使用 T-Mobile 网络。主要差别是 Ultra Mobile PayGo 支持中国境内漫游，即使没有 Wi-Fi 也能通过漫游接收短信；Tello 没有漫游，必须依赖 Wi-Fi 通话。价格上 PayGo 的月费更低，但套餐内容也更小。

Wi-Fi Calling 在国内为什么开不了？

常见原因有四个：运营商账户没有开通该功能；部分运营商只允许连接美国基站时启用；网络出口连不到运营商的通话服务器；手机端开关没打开或需要重新插拔 SIM 卡。需要按顺序排查。

境外 eSIM 在中国能用吗？

能。境外发行的数据 eSIM 在中国通过漫游接入中国移动、中国联通或中国电信的网络，数据经境外网关出口，不需要额外配置即可使用。

国行 iPhone 能用 eSIM 吗？

大部分不能。中国内地销售的 iPhone 长期采用双实体 nano-SIM 设计，没有 eSIM 硬件。中国自 2025 年 10 月起开放了运营商手机 eSIM 业务，但办理需要中国身份证实名，机型支持范围也很有限，购买前务必确认自己机型的具体型号。

美国号码怎么长期保号？

核心是不要欠费且保持账户活跃。多数预付费号在余额不足并长期不续费后会被回收，建议开启自动续费，并定期产生一次通话或短信记录。具体规则以运营商条款为准。

用 Wi-Fi Calling 收银行验证码可以吗？

可以，前提是该运营商支持通过 Wi-Fi 通话收发短信，且账户状态正常。部分机构会限制向 VoIP 或漫游号码发送验证码，银行类短信是否可达最终取决于对方的风控策略。
